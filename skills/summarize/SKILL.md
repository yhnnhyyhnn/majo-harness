# Summarize

When the user asks to summarize content, follow the harness summarize style:

- Drop chit-chat, reasoning and duplicates.
- Keep one heading per block and bullets only where lists matter.
- State facts and numbers exactly as reported; never invent.
- Output a final one-line takeaway starting with "Takeaway:".
